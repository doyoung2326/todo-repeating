새로 넣고 싶은 기능: **$ARGUMENTS**

CLAUDE.md의 "새 기능은 반드시 TDD로" 규칙에 따라 진행한다.
지금 응답에서는 **0단계와 1단계까지만** 하고 멈춘다.

## 0. 명세
위 아이디어를 검증 가능한 요구사항 목록으로 정리한다.
- 입력 → 기대 출력
- 엣지 케이스 (빈 값, null, 경계 날짜, 중복, 잘못된 입력)
- 실패 시 동작 (에러 메시지 / HTTP 상태 코드)
- 어디에 들어가는 기능인지: `backend/lib/` 순수 로직 / API 라우트 / 프론트 컴포넌트

애매한 부분이 있으면 여기서 질문하고 멈춘다.

## 1. Red
명세대로 **테스트 파일만** 작성한다. 구현 코드는 한 줄도 쓰지 않는다.
그다음 `npm test`를 실제로 실행해서 실패를 확인하고, 실패 출력을 그대로 보여준다.

마지막에 다음 한 줄로 끝낸다:
> 테스트가 명세대로면 "구현해줘"라고 알려주세요. 그때 Green 단계(최소 구현)로 넘어갑니다.
